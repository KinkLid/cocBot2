# Защита админского просмотра переписок

Административный просмотрщик показывает сохранённые переписки прямо в Telegram и удаляет сообщение по кнопке `✖️ Закрыть`.

Сообщения просмотрщика содержат чужие персональные данные, поэтому они отправляются через `suppress_outgoing_conversation_logging()` и не записываются повторно в журнал самого администратора. Подавление действует только внутри конкретного вызова отправки, редактирования или удаления сообщения просмотрщика. Остальные исходящие сообщения бота продолжают журналироваться штатно.
