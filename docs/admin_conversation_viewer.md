# Просмотр переписок в админке

Администратор использует кнопку `💬 Переписки с ботом` в основном меню.

Поток:

1. Бот показывает inline-список пользователей, для которых есть `user_<telegram_id>.jsonl`.
2. По нажатию открывается последняя страница переписки.
3. Кнопки `Старее` и `Новее` переключают страницы прямо в том же сообщении.
4. Кнопка `К списку` возвращает список пользователей.
5. Кнопка `✖️ Закрыть` удаляет сообщение с историей из Telegram-чата администратора.

Скачивания журналов через этот интерфейс нет.

Доступ проверяется через существующий `AuthService`; не-администраторы получают отказ. Player token повторно защищён при отображении: записи с `secret_redacted=true` или состоянием `waiting_for_player_token` показываются как `[секрет скрыт]`.
